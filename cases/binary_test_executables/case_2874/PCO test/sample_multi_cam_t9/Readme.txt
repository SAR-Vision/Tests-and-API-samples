This test is compatible with the PCO camera only !!!!

Before performing the test:
1. Check that FG index is correct (gnum parameter)
2. Check the number of loops (loop parameter) and number of frames per loop (ima_count parameter)
3. Open Vision Point and change Pulse Message Mode parameter to advanced


After the test, check that there are no missing or failed images (in the logs: "0 images missing, 0 image failed"  per loop)
