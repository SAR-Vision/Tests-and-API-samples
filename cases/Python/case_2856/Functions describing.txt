| Function                                                          | What it does                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CaseArgumentParser()`                                            | Defines all command-line parameters used by the test: device, camera, resolution, pixel formats, and expected RAW files.                                                                                                                                                         |
| `Reset_grabber(grabberHandle)`                                    | Resets/configures the frame grabber to a known initial state, including CXP connection, trigger mode, and pulse-message settings.                                                                                                                                                |
| `Reset_camera(cameraHandle, grabberHandle)`                       | Reads `KAYA_Known_cameras.json`, finds the detected camera, and applies its predefined camera/grabber reset sequences.                                                                                                                                                           |
| `ParseArgs()`                                                     | Parses the actual command line and converts the arguments into a Python dictionary.                                                                                                                                                                                              |
| `Stream_callback_func(buffHandle, userContext)`                   | Called by the SDK when a frame arrives. Copies the frame into a NumPy array, signals that a frame was received, and returns the buffer to the acquisition queue.                                                                                                                 |
| `numpy_from_data(buffData, buffSize, datatype)`                   | Converts the raw SDK memory buffer into a NumPy array without manually copying each value.                                                                                                                                                                                       |
| `acquire_one_frame(cameraHandle, datatype, timeout=15)`           | Creates a stream, allocates buffers, starts acquisition, waits for one frame, stops acquisition, deletes the stream, and returns the acquired frame.                                                                                                                             |
| `pixel_format_datatype(pixel_format)`                             | Selects the appropriate NumPy storage type: `uint8` for ≤8-bit formats and `uint16` for formats above 8 bits such as Bayer10/RGB10/Bayer16.                                                                                                                                      |
| `camera_name_for_file(camera_model)`                              | Converts a camera model name into a filename-safe form by replacing characters such as `/` with `_`.                                                                                                                                                                             |
| `camera_matches_request(...)`                                     | Determines whether a detected camera should participate in the current test. Supports exact names, `Chameleon`, `Iron`, wildcards, and the generic Iron RAW-file configuration.                                                                                                  |
| `_numbered_pair_candidates(before_path, after_path, max_index=9)` | Generates possible RAW filename pairs: original `before/after`, then `before1/after1`, `before2/after2`, etc.                                                                                                                                                                    |
| `resolve_expected_raw_pair(...)`                                  | Searches the test folder for the correct pair of golden RAW files for the detected camera and configuration.                                                                                                                                                                     |
| `load_expected_raw(path, datatype)`                               | Opens a golden RAW file and loads its contents into a NumPy array using the required datatype.                                                                                                                                                                                   |
| `validate_expected_raw_sizes(...)`                                | Checks that the golden RAW files have exactly the expected number of pixels/components for the selected resolution and pixel formats.                                                                                                                                            |
| `CaseRun(args)`                                                   | Main test function. Opens the frame grabber, finds matching cameras, configures them, runs **PASS 1 without debayering**, compares against `before.raw`, then runs **PASS 2 with hardware debayering** and compares against `after.raw`. Finally closes all hardware resources.  |
